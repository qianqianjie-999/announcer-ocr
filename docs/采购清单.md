## 一、整机配置单（Linux 迷你主机）

**本系统实际负载**（供选型参考，配置不必高于此）：

## 二、五项必查（缺一项现场就会踩坑）

1. **BIOS 支持「来电自启」**（Restore AC Power Loss / AC Back → Power On）
   —— 大厅断电恢复后无需人工按开机键，无人值守的关键。
2. **音频输出可用**：Linux 下**别依赖 HDMI 出声**（PipeWire 默认 sink 不一定是 HDMI）。优先走主板 3.5mm，或花 30 元买个 USB 声卡最稳。
3. **千兆网口**：RTSP 1080p 约 2~8 Mbps，百兆理论够但不稳妥，选千兆。
4. **内存 ≥ 8 GB**（推荐 16 GB）：OCR 模型 + RTSP 缓冲在 4 GB 上会很紧张。
5. **无风扇 + 12V DC 常开**：7×24 运行，风扇积灰是主要故障源。

> **不推荐树莓派 4/5**：RapidOCR 单帧推理要 1.5~3 秒，播报延迟会到 5 秒以上；同价位 N100 小主机快 3~5 倍。

## 三、操作系统

- **Ubuntu Server 24.04 LTS**（首选，5 年支持，依赖全是 apt 一条命令）
- 或 Debian 12；
- **装无桌面最小版**（不装 Desktop），省内存 + 少一堆更新弹窗；
- 部署方式：接一次显示器+键盘装系统 → 之后全程 SSH 远程管理。

配套脚本（已在项目目录）：

```bash
sudo bash install.sh          # 装依赖 + 建 venv + 注册 systemd
sudo systemctl start announce # 启动，崩溃 5 秒自动拉起
journalctl -u announce -f     # 看日志
```
